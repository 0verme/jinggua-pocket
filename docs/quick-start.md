# 开发预览版快速开始与限制

> 本文只描述当前开发预览版的软件交互，不代表 v1.0 已发布、已完成实机验收或适合量产。Issue #18 仍 OPEN，仓库当前没有 GitHub Release / 固件附件；设备屏幕、按键、功耗、外壳和 OTA 真机验收均须按下文状态另行验证。

## 目标与烧录

当前固件目标只有 M5Stack StickS3 / ESP32-S3。安装 PlatformIO 后，在仓库根目录构建并按需上传：

```sh
pio run -e m5stack-sticks3
pio run -e m5stack-sticks3 -t upload
pio device monitor -b 115200
```

默认构建不含 Wi-Fi 凭据，启动时 radio 保持关闭，可离线运行。请勿把真实 SSID、密码、API URL 或 CA 配置提交到仓库；需要开发环境配置时，按 README 的「Wi-Fi/API 开发配置」设置环境变量。正式用户配网尚未实现，设备绑定、二维码、历史云同步与产品语音也尚未交付。

## 离线起卦

1. 启动后首页显示“静卦 / 摇一摇 / 或按 A”。按 A 进入准备页，再按 A 开始。
2. 起六爻时可按 A 逐爻操作；Shake 输入已接入软件路径。每爻展示动画/结果后继续，直到六爻完成。
3. 结果页显示本卦、动爻和离线 `CODE NNNN`；有动爻时按 A 查看之卦。用户可在 <https://gua.overme.cn/> 输入四位码还原同一卦象。编号从六个完整爻值本地确定性计算，结果/历史均不需要联网；按 B 的既有上传入口保持不变。
4. 首页的 B 入口打开 Wi-Fi 设置。设置页显示当前固件构建版本（来自 `JINGGUA_FIRMWARE_VERSION`；开发默认 `0.2.0`，最长支持 24 个 ASCII 字符并分两行显示），也可长按切换声音开关。

A/B 和 Shake 是当前固件定义的输入映射；BtnB 物理路径以及整套屏幕交互尚未完成当前设备验收。请将实际操作结果记录为 `PENDING_HARDWARE_VALIDATION`，不要仅凭 host 测试或代码渲染标为硬件 PASS。

## 联网与 OTA

Wi-Fi 连接只能由用户从设置页主动触发，凭据仅通过构建期环境变量注入；没有配网向导或持久化凭据设置 UI。只有在有效开发配置下才能测试 Wi-Fi/API；完整起卦后的结果页 B 才会触发一次 API 上传，不会自动上传问题文本或后台同步。设备绑定、QR 分享、历史同步的服务端契约仍未完成。

OTA 需要先连接 Wi-Fi，再从已连接页显式进入检查/安装流程。当前仓库没有 Release manifest 或固件资产，因此现在没有可供设备安装的 v1.0 更新；不要据此创建或宣称有正式发布。真实下载、版本切换、掉电保护与 bootloader rollback 仍待 StickS3 实测，详见 [`ota.md`](ota.md)。
