# JingGua Pocket v0.3.0

## 版本概览

这是 JingGua Pocket 的首次**累积预览版**：此前没有成功发布的 GitHub Release 或版本 Tag，本版本按可追溯 main 历史汇总交付，不是只发布 Issue #42，也不是正式 `v1.0`。本次审计覆盖 21 个已合并 PR（#20–#43 中实际合并到 main 的 PR）及 main 上的 Phase 0 基础提交；完整审计表见 [`v0.3.0-audit.md`](https://github.com/0verme/jinggua-pocket/blob/v0.3.0/docs/releases/v0.3.0-audit.md)。

目标设备为 M5Stack StickS3 / ESP32-S3。代码、Native/CI 和固件编译验证不等于真实设备验收；屏幕、按键手感、IMU、声音、功耗、OTA 更新与外壳仍有硬件待验项目。

## 新增功能

- **长按 A 自动成卦（Issue #42）**：短按 A 继续逐爻起卦；A 长按阈值为 1000 ms，可从 0～5 条既有爻自动补齐六爻，不重置已有爻。自动流程逐次调用既有随机/领域层路径，完成后自动进入本卦结果页。
- **摇动起卦**：基于 BMI270 加速度/角速度检测与释放门限、峰间隔和 cooldown；按键仍可使用。
- **离线历史与卦象码**：完整卦象按既有环形 NVS 历史路径保存；结果页和历史页均可推导离线 `CODE NNNN`，无需联网。
- **离线优先 Wi-Fi/API**：Wi-Fi 默认关闭，只在用户显式连接；已完成卦象的上传由用户在结果页主动触发。没有设备绑定、二维码分享或历史云同步。
- **安全 OTA 软件路径**：用户显式检查/安装，校验 manifest、HTTPS、SHA-256、镜像长度/ESP image，并使用 inactive OTA slot 与 bootloader rollback；本版本实际的 prerelease 与设备固定的 `releases/latest` 查询之间有下文所述限制。

## 交互与视觉优化

- 三枚铜钱使用非阻塞、串行动画；铜钱造型、旋转和结束姿态经过软件改进。
- 中文字体、135×240 小屏布局、结果页、状态与进度提示持续优化；长按自动成卦显示 `正在成卦 n/6`。
- 合成 Start/Cast/Complete/Error 声音反馈；可在设置页切换声音。
- 附 StickS3 bumper CAD 草案、BOM 与验证计划（不是已制造或验收的外壳）。
- 短按、B 按键、Shake、其他页面既有长按、唤醒和 OTA 操作继续使用各自既有语义。自动成卦时输入被锁定、Shake 检测重置，并禁止自动息屏。

## 稳定性与问题修复

- 历史恢复路径增加 CRC、孤儿记录核对和 NVS recovery journal，读取错误时 fail closed；启动时记录 reset reason。
- OTA 取消与激活的竞态收敛到安全 finalization 边界。
- 按键 debounce、状态机、Wi-Fi/API 错误与重试、动画生命周期和低功耗路径均有对应 Native 测试或软件门禁。
- Issue #42 的新流程不改变卦象/离线码算法、历史记录格式、NVS 布局或现有 Wi-Fi/API 行为；没有引入破坏性存储迁移。

## 联网与 OTA

设备不会因启动、起卦或待机自动打开 Wi-Fi；上传、OTA 检查和安装均要求用户操作。发布构建不注入私有 Wi-Fi 密码、API URL/Token 或用户数据；OTA TLS 使用公开 Sectigo 根 CA 信任锚。SHA-256 用于镜像完整性核验，**不是独立代码签名**；仓库未声称启用独立离线签名或 Secure Boot。

设备当前固定查询 `https://github.com/0verme/jinggua-pocket/releases/latest/download/firmware-manifest.txt`。GitHub 的 `releases/latest` 通常不选择 prerelease，因此 `v0.3.0` 预览资产**可通过 USB 下载/烧录，但不会由该固定 OTA 地址发现**。未来正式稳定版若发布为非 prerelease 且版本号递增，才可由既有 OTA 检查路径发现；真实 OTA 下载、取消、掉电和 rollback 仍待真机验收。

## 兼容性说明

- 固件目标：M5Stack StickS3 / ESP32-S3，PlatformIO `m5stack-sticks3`。
- 使用 `default_8MB.csv`：NVS 独立于 app slot；`ota_0` / `ota_1` 各为 `0x330000` 字节。已构建镜像须小于单 app slot。
- 本次没有修改历史记录/NVS schema，也没有添加自动擦除或迁移。完整 USB 烧录包写入 bootloader、partition table、`boot_app0` 与 app image，但不会调用 `erase_flash`；对已经有重要数据的设备，先核对当前分区兼容性并自行备份。
- Wi-Fi 默认关闭。固件不包含用户私有配置；凭据应由用户在自己的开发/设备配置流程中设置。

## 验证结果

- Native Tests / CTest：Release 配置通过，43,507 assertions、0 failures。
- PlatformIO `m5stack-sticks3`：编译通过，`firmware.bin` 为 1,221,520 bytes（小于 `0x330000` app slot）。
- `tools/check_format.py`、`tools/check_font_asset.py`、`tools/check_ota_support.py`：通过；字体 328 glyph / 48,050 bytes，双 OTA slot 与 bootloader rollback 检查通过。
- `python3 -m unittest discover -s test/python -p "test_*.py"`：9 tests 通过。
- 发布准备 PR 以 Native、PlatformIO、Format/Lint GitHub CI 通过为合并门禁；该软件门禁不代表真实设备通过。
- 这些均为软件/构建证据，不代表真实设备通过。

## 已知限制

- 本次没有连接或烧录 StickS3；A 长按触发手感/误触、0～5 爻自动补全、动画串行与观感、屏幕字形、声音、Shake、显示关闭/Light Sleep 唤醒和功耗均为 `PENDING_HARDWARE_VALIDATION`。
- OTA 预览版资产不被当前 `releases/latest` OTA 地址发现；真实更新、取消、断电恢复和 rollback 未在设备上验证。
- BtnB 物理输入路径在既有 bring-up 记录中仍有未决真机核验；本次软件测试不将其改标为 PASS。
- 麦克风 PR 只交付短 PCM 统计研究，没有语音识别、语音问事或语音上传产品流程。
- 设备绑定、二维码同步、历史云同步、正式 Wi-Fi 配网、量产外壳和 v1.0 发布仍未完成。Issue #18 不因本次预览发布关闭；Issue #42 保持 Open，等待 StickS3 验收。
- 仓库没有 `LICENSE` 文件且 README 仍标记 License `TBD`；本次不选择或暗示任何开源许可证，v0.3.0 也不代表授予额外的第三方再分发权。
